<details>
<summary><b>💰 SmartExpense — Student Edition</b></summary>

<br />

**SmartExpense** is a full-stack personal finance platform focused on transaction tracking, budgeting, savings planning, analytics and multi-currency financial management.

| Area | Details |
| --- | --- |
| **Frontend** | React 19, Vite, Tailwind CSS, Redux Toolkit, React Router, Recharts |
| **Backend** | Node.js, Express.js, MongoDB, Mongoose |
| **Security** | JWT, bcrypt, Helmet, rate limiting, validation |
| **Features** | Transactions, budgets, savings goals, analytics, CSV export, admin RBAC |
| **Financial Engine** | Deterministic calculations with multi-currency support and historical exchange rates |
| **Email** | Nodemailer + Brevo SMTP |
| **Deployment** | Vercel + Render + MongoDB Atlas |
| **Verification** | 187 backend tests across 29 suites + frontend lint/build verification |
| **Repository** | [GitHub](https://github.com/Anikesh-Jain/smart-expense) |
| **Live** | [smart-expense-blond.vercel.app](https://smart-expense-blond.vercel.app/) |

The project was built with an emphasis on user isolation, security, maintainability and production deployment.

</details>
